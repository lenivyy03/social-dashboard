Términos de servicio

Social Dashboard Lenivyy03 · Actualización: 30 de octubre de 2026

Versión de desarrollo. Social Dashboard Lenivyy03 es un proyecto para consultar estadísticas y preparar contenido de cuentas administradas con autorización. La integración con TikTok está en preparación para pruebas Sandbox; estas páginas no acreditan aprobación de TikTok ni habilitan publicaciones públicas.

1. Responsable y alcance

Angel Ortega mantiene este proyecto. Estos términos describen el uso de la aplicación disponible en este sitio y de sus funciones habilitadas. Puedes consultar estas páginas sin conectar una cuenta. Antes de conectar cuentas o utilizar funciones nuevas, revisa los términos y el aviso de privacidad vigentes.

2. Funciones disponibles

El dashboard consulta datos de Facebook e Instagram mediante Meta Graph API con los permisos que concedas. Permite comparar publicaciones, guardar históricos en el navegador, preparar borradores y exportar reportes. La versión actual no ofrece un servicio de publicación programada ni una conexión funcional con TikTok.

Las futuras pruebas con TikTok requerirán autorización de la cuenta, permisos habilitados y los límites del entorno de prueba. Una subida como borrador y una publicación directa son operaciones diferentes. Una función solo se considerará completada cuando su estado haya sido confirmado por la plataforma.

3. Uso autorizado

  • Conecta únicamente cuentas propias o cuentas que tengas autorización para administrar.
  • Utiliza contenido original o para el que tengas los derechos, licencias y consentimientos necesarios, incluida música e imágenes de terceros.
  • Respeta las condiciones de Meta, TikTok y cualquier plataforma que utilices. No emplees el proyecto para eludir restricciones, enviar spam o acceder a cuentas ajenas.
  • Evita introducir datos médicos, expedientes, contraseñas de redes sociales o información personal sensible en los borradores y reportes.

4. Control de tu contenido

Conservas los derechos sobre tus archivos y textos. Preparar un borrador o conectar una cuenta no constituye una autorización general para publicar. Si se habilitan envíos a una plataforma, deberán mostrar la cuenta de destino y el contenido para obtener tu autorización antes del envío. El proyecto no adquiere derechos para vender o reutilizar tu contenido en publicidad propia.

5. Disponibilidad y resultados

El proyecto se encuentra en desarrollo. Las funciones pueden cambiar o presentar interrupciones. Las estadísticas dependen de los datos y permisos que entregue cada plataforma y pueden estar incompletas. No se prometen resultados de alcance, ventas, aprobación de aplicaciones ni una hora de publicación garantizada. Conserva respaldos de los datos que necesites.

6. Costos y servicios externos

Esta versión del proyecto no tiene un sistema de cobro ni una suscripción comercial. Si se proponen servicios de alojamiento, almacenamiento o IA de pago, su contratación y costos deberán acordarse por separado. No se realizan cargos mediante estas páginas.

7. Dejar de usar la aplicación

Puedes dejar de usar el dashboard, borrar sus datos locales y revocar las conexiones desde la configuración de cada plataforma. Consulta la política de privacidad para conocer qué se guarda y cómo eliminarlo. Revocar una conexión no elimina publicaciones ya existentes en la red social.

8. Cambios y contacto

Las actualizaciones de estos términos se publicarán aquí con una nueva fecha. Antes de habilitar funciones que cambien el tratamiento de datos, se actualizará también el aviso correspondiente. Para soporte o dudas, abre una solicitud en el repositorio del proyecto. Ese canal es público: para solicitudes de privacidad, pide primero un canal privado sin adjuntar tokens ni datos personales.
