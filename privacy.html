Política de privacidad

Social Dashboard Lenivyy03 · Actualización: 30 de octubre de 2026

Alcance actual. Este aviso describe la versión del dashboard que guarda información en el navegador. La integración de TikTok está en preparación para pruebas Sandbox. No existe todavía un servidor de este proyecto que reciba credenciales de TikTok o ejecute publicaciones.

1. Responsable y contacto

El responsable del proyecto Social Dashboard Lenivyy03 es Angel Ortega. Para dudas, acceso, corrección, eliminación u oposición al uso de datos que pudiera tener el responsable, inicia una solicitud en GitHub Issues pidiendo un canal privado. Los mensajes en ese sitio son públicos; no incluyas datos personales, tokens ni documentos en ellos. Para datos guardados únicamente en tu navegador, sigue también las instrucciones de eliminación de esta página.

2. Datos que utiliza el dashboard

  • Conexión con Meta: el token de acceso que introduces, identificadores y nombres de páginas, cuenta profesional de Instagram vinculada y datos accesibles con tus permisos.
  • Contenido y estadísticas: textos, fechas, identificadores, imágenes de referencia y métricas de publicaciones, seguidores e interacciones que devuelve Meta.
  • Información que capturas: perfiles de audiencia, borradores, objetivos, vínculos entre publicaciones y cifras de gasto, mensajes, prospectos, ventas e ingresos. Estos campos están destinados a planificación y cifras agregadas, no a expedientes de personas.
  • Archivos y exportaciones: el laboratorio actual guarda el nombre del archivo de referencia; no lo sube a un servidor. Los reportes y respaldos que descargas quedan bajo tu control.

3. Finalidades

La información se utiliza para consultar estadísticas de cuentas autorizadas, comparar contenido, conservar históricos, preparar ideas y generar reportes. El código actual no incorpora un modelo de IA conectado: el texto para Codex se genera localmente. Si lo copias a un servicio de IA, revisa qué información incluyes y la política de ese proveedor.

4. Dónde se guarda y durante cuánto tiempo

El token de Meta y las preferencias, borradores y otros registros se guardan en localStorage del navegador. Los históricos y la caché de publicaciones se guardan en IndexedDB. Los registros locales permanecen hasta que los borres, el navegador elimine su almacenamiento o una función de la aplicación los reemplace. Algunos datos temporales se actualizan al cargar nuevas consultas.

GitHub aloja el código y las páginas del sitio; el funcionamiento actual no envía automáticamente tus reportes o borradores al repositorio. Cualquier archivo que exportes seguirá existiendo donde lo hayas guardado hasta que lo elimines.

5. Proveedores y transferencias

Las solicitudes de estadísticas se envían a Meta con tu token. GitHub Pages sirve el sitio. El dashboard también solicita fuentes a Google Fonts y una biblioteca de exportación a jsDelivr. Al conectarse con ellos, esos proveedores pueden recibir datos técnicos como dirección IP, navegador y URL solicitada, y tratarlos conforme a sus propias políticas. Las páginas de términos y privacidad no cargan fuentes, bibliotecas ni scripts externos.

El proyecto no incorpora publicidad ni herramientas propias de seguimiento comercial y no ofrece los datos a la venta. Revisa las políticas de GitHub, Meta, Google y jsDelivr para conocer sus tratamientos independientes.

6. Pruebas previstas con TikTok

Configurar una aplicación en TikTok Developers no conecta por sí solo una cuenta al dashboard. Cuando la integración esté implementada, antes de autorizarla se informará de los permisos solicitados y del destino de los datos. Los permisos configurados para la prueba son user.info.basic (identificar la cuenta), video.publish (publicación directa) y video.upload (envío de borradores); solo se solicitarán los que necesite cada flujo.

Antes de activar un servidor o almacenar tokens, videos o estados de envíos de TikTok, este aviso se actualizará para identificar el alojamiento, conservación, eliminación y medidas aplicables. Los archivos que decidas enviar a TikTok estarán también sujetos a su política de privacidad y a las restricciones de Sandbox. No se presenta esta versión como una integración aprobada para producción.

7. Cómo eliminar datos y revocar acceso

  1. Para eliminar los datos locales, abre la configuración de tu navegador y borra todos los datos del sitio de este dashboard, incluidos el almacenamiento local e IndexedDB. Esto elimina también históricos y borradores locales; exporta antes lo que quieras conservar.
  2. Para impedir nuevas consultas a Meta, revoca la aplicación desde las opciones de aplicaciones o integraciones de tu cuenta de Meta. Borrar el navegador por sí solo no revoca un token.
  3. Si autorizas una prueba con TikTok, puedes retirar el acceso desde las opciones de aplicaciones conectadas de TikTok. La eliminación local o revocación no elimina archivos o publicaciones que ya estén en TikTok.
  4. Elimina por separado reportes y respaldos descargados y sus copias. Si compartiste datos con el responsable, solicita su acceso, corrección o eliminación mediante el canal indicado arriba.

8. Protección y cambios

El acceso al navegador y sus datos permite acceder a los registros guardados. Usa un dispositivo y perfil de navegador de confianza. Los tokens no deben publicarse en GitHub ni incluirse en reportes o capturas. La información de esta página se actualizará antes de introducir nuevos tratamientos o proveedores; la fecha de la última versión aparece al inicio.
